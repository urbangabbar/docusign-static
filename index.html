The standard

Everything we ship has to pass the same test.

We published the test before we published the products. A shallow version of this on four platforms would be worse than a deep version on one — so we go one platform deep. If a thing cannot see the record, know what changed, and act on it, we don't ship it. We called it the four levels of integration; internally we just call it see, know, do.

Depth is the product

See, know and do — or it doesn't ship. That's why we build for one platform instead of five.
