Export GoHighLevel opportunities to Google Sheets

By Karthik Anand · Updated October 16, 2026

For a one-time export, open the relevant GoHighLevel Opportunity Smart List, use its menu to export a CSV, and open that file in Google Sheets. Preserve one row per deal and its CRM ID. For recurring reporting, LC Bridge’s early-access import is designed to save the dataset, fields, filters, and refresh schedule.

Export a native opportunity list as CSV

Open the Opportunity Smart List that contains the deals you want to analyze. Review its current scope, then use the top-right menu beside Add Opportunity and choose Export. HighLevel documents this as a CSV export of the records returned by that list’s current setup. Import the completed file into a new Google Sheet.

Before calculating totals, inspect the file’s actual columns and a few source records. Keep an untouched copy and note which account, list, filters, and date produced it. A saved list can standardize the view, while each manually downloaded file remains a separate reporting snapshot.

An opportunity is not a contact

One customer can have several opportunities. If a spreadsheet collapses deals to one row per contact, it can discard genuine sales activity. If it joins every opportunity to every payment for the same contact, it can instead repeat amounts and inflate totals.

Choose opportunity ID as the primary grain for a pipeline export. Carry contact ID as a relationship field. Keep an opportunity title for readability, but do not use the title as the matching key for future updates.

Bring enough fields to explain a deal

A useful working set includes the opportunity ID, title, pipeline, stage, status, owner, value, currency, created date, and qualifying status date. Add selected custom fields when your team uses them to make a decision. Preserve missing owners and missing values explicitly.

Separate fields that describe the current record from fields that describe an observed event. The current stage says where a deal is now. A stage-entry timestamp describes a particular transition only when the source provides that meaning.

Use the pipeline sample to inspect the result

Pipeline & Follow-up combines current open-stage bars, sales-versus-target progress, monthly sales metrics, and deal details. Current open pipeline is an as-of view. The chart should not pretend that today’s open-stage mix was the stage distribution on every earlier day.

Switch the sample owner filter and compare the summary with its supporting records. This is a quick way to see why a useful export needs identity, ownership, dates, and currency rather than a list of deal amounts alone.

Handle different currencies deliberately

A USD pipeline total should not silently add EUR opportunities. Keep the currency on each deal and explain exclusions from the displayed sum. Convert amounts only when you have a chosen conversion method, exchange-rate source, and date basis.

Also keep a missing value different from a zero-value deal. A zero can be a valid recorded amount. A missing amount is a data-quality issue that a dashboard should surface rather than hide.

Example: one contact, two opportunities

An invented customer has a $1,200 service opportunity and a $300 renewal opportunity. A contact-level export can show one customer while a deal-level export correctly contains two rows. Grouping by contact before checking the deal grain can hide the renewal or combine two different pipeline stages.

Separate reporting from CRM changes

Reading opportunity data into a worksheet does not authorize changes back to the CRM. LC Bridge’s reviewed-update design requires a matching existing record, eligible fields, a fresh preview, and explicit confirmation.

The public sample does not connect to an account or write anything. Use it to evaluate the report arrangement. For the planned connected workflow, request early access and choose refresh frequency with per-transfer usage in mind.
