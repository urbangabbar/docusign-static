Google Sheets integration · Practical guide

Build a GoHighLevel sales pipeline dashboard in Google Sheets

On this pageStart with the questions for the next sales meetingKeep one row per opportunityUse the right chart for each comparisonUse filters to explain a resultRead the sample’s numbers as a meeting agendaTurn attention into a specific follow-up

By Karthik Anand · Updated October 16, 2026

A useful GoHighLevel pipeline dashboard combines the current open pipeline with sales progress and a record-level follow-up table. Keep current-stage value separate from historical conversion. LC Bridge’s Pipeline & Follow-up sample shows that arrangement with owner filters and invented opportunity data.

Start with the questions for the next sales meeting

How much open value is in each stage? Which deals need attention? How much has been won against the chosen target? Those questions need different views of the data. A single funnel picture cannot answer all three well.

Use a current-stage chart for today’s open opportunities. Use qualifying won outcomes and a configured target for progress. Keep the underlying deal table close enough that a manager can inspect a surprising number.

Keep one row per opportunity

Preserve Opportunity ID, contact relationship, pipeline, stage, status, owner, amount, currency, and relevant dates. A contact can have more than one opportunity. Aggregate at deal grain before joining other information into the report.

When a value or stage-entry date is missing, surface the limitation. A missing amount should not become a valid zero. A missing stage-entry date cannot support a reliable “days in stage” figure.

Use the right chart for each comparison

The sample places open-stage bars beside sales-versus-target progress. Stage bars use a shared zero baseline so their lengths are comparable. The progress view identifies actual outcomes and the target instead of presenting an unsupported forecast band.

Use Sales & Goals for an actual-versus-target monthly comparison. Use Stage Conversion & Bottlenecks only when observed stage history exists. Separating these purposes keeps the pipeline page readable and the labels honest.

Use filters to explain a result

Try the sample owner filter. Compare the KPI change with the chart and the underlying rows. The same source facts should drive each part of the report. A filter that changes a chart but leaves its total unchanged creates avoidable confusion.

Keep the date basis visible. Open pipeline is a current snapshot, while sales outcomes use the report’s qualifying status date. A date selector does not turn every metric into a historical snapshot.

Read the sample’s numbers as a meeting agenda

The open Pipeline & Follow-up sample starts with nine open deals worth $22,050 in the configured currency. Selecting Alex Morgan reduces that view to two open deals worth $3,050. Both values are valid because the owner scope changes. They are not competing versions of the same total.

The record table makes the next action concrete: inspect the deal, its current stage, time in stage, next linked task, and any attention reason. A missing owner or missing date should remain visible as a reporting exception. Do not replace it with an invented value merely to make the chart look complete.

Use this as a rehearsal for your own meeting: state the scope, explain the number, find its supporting records, then decide the follow-up.

Turn attention into a specific follow-up

A deal table should show which records need action and why. Overdue tasks and stage-age exceptions are useful when supported by actual deadlines and observed dates. They should not be inferred from a generic last-updated timestamp.

Explore the sample, read its metric definitions, and compare it with your weekly review. The early-access integration is designed to deliver the connected version in Google Sheets. Source refreshes are metered by transferred records; existing worksheet data can be analyzed without another provider transfer.
