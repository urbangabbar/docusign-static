What the metrics mean

Current incomplete tasks

Record grain: task

Date basis: As of latest refresh

Rules: One contributing record per typed ID

Current overdue tasks

Record grain: task

Date basis: As of latest refresh

Rules: One contributing record per typed ID

Currently completed tasks

Record grain: task

Date basis: As of latest refresh

Rules: Completed flag is not a dated completion event

Notes added

Record grain: note

Date basis: Recorded date in selected period

Rules: One contributing record per typed ID

Required data and boundaries

  • Contact tasks
  • Dated note metadata
  • Contacts

A current completed flag is not a dated completion event. Notes are counted by their recorded dates; no note bodies or unsupported employee rankings are exposed.

Task completion is a current flag; there is no completed-in-period chart without a completion timestamp. Note metadata only; note bodies are not required for reporting.
