Create and customize a report

On this pageChoose the report for the business questionProvide only relevant setup inputsKeep the worksheet relationship stableRead limitations with the result

By Karthik Anand · Updated October 16, 2026

Choose a template, supply its relevant inputs in one form, inspect the sample, and create the report worksheet. A report can reuse compatible source imports. Its metrics still depend on the source grain, relationships, date basis, and available history.

Choose the report for the business question

Use Leads & Sources for recorded contact origins, Pipeline & Follow-up for current open deals and attention, Sales & Goals for configured targets, and Invoice Aging for current unpaid balances. A report’s name should match the question it answers.

Explore the public preview before requesting access. The full library contains 25 supported synthetic templates. Workflow Performance is excluded because current workflow definitions do not establish execution history.

Provide only relevant setup inputs

Period-based reports need an intentional reporting period. Appointment reports need calendar and attendance meanings; stage conversion needs an observation window; forecast movement needs a compatible saved cutoff. Custom Records requires a selected schema and verified association mapping.

Goals are configured inputs, not assumed benchmarks. A sales total can remain useful without a target, but target attainment must remain unavailable until an appropriate goal exists.

Keep the worksheet relationship stable

The reviewed prototype delivers reports as workbook worksheets. Edit uses the same report form and saves one draft. Duplicate report creates an independent report worksheet. Rebuilding should preserve worksheet identities and customer formula areas.

Native Google Sheets delivery remains subject to production acceptance. The public HTML sample demonstrates calculations and arrangements rather than claiming that a workbook has been installed.

Read limitations with the result

Current open pipeline is a snapshot. Historical conversion needs stage events. Collected cash differs from won opportunity value. A payment sharing a contact with a deal does not prove a direct allocation. Keep these distinctions in the report labels.

Report calculations using already delivered worksheet data do not create another provider transfer by themselves. A source refresh that delivers records is separately metered by actual successful primary record transfers.
