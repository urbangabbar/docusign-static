Getting started with CRM Sync

On this pageExplore before connectingPrepare the account and destinationChoose your first jobKnow the usage model

By Karthik Anand · Updated October 16, 2026

CRM Sync is the in-app name of the Google Sheets integration for GoHighLevel by LC Bridge. The connected product is in early access. Start with an open sample report, then use the existing waitlist to request access. Joining the waitlist does not install the app or authorize account access.

Explore before connecting

Open the template library and choose the report closest to your job. Each preview uses invented data and a fixed October 2026 sample period. Owner and period filters work locally. No sample connects to a Google account, a CRM account, or a billing service.

Read the required sources and metric definitions. Some reports need more than current records: stage conversion needs observed transitions, forecast movement needs a compatible saved cutoff, and recurring revenue changes need an event ledger.

Prepare the account and destination

When access is enabled for your team, use a CRM account you are authorized to connect and a Google account with access to the intended spreadsheet. Choose a destination whose sharing settings match the sensitivity of the records. A hidden tab is not an access boundary.

The app uses neutral CRM wording. Its public acquisition name and in-app name refer to the same integration. Actual installation links and account permissions are supplied with access; this guide does not ask you to authorize an unavailable installation.

Choose your first job

For data movement, choose Sync CRM data and create an import. For reporting, choose Create or view reports and select a template. The first import should use a bounded dataset that you can compare with its source.

New imports default to import-only. Eligible outgoing updates require explicit preview and confirmation. Enabling update permission does not send changes by itself.

Know the usage model

The planned monthly allowance covers 250 successful primary record transfers. Each later execution transferring records creates additional usage, including repeat transfers of the same records. Supporting lookups are bundled. Review the exact rates and optional calculator before choosing a recurring schedule.

For high-volume work, use Talk to Sales to discuss a custom subscription. Live provider delivery and billing are enabled through the actual production access process, not through the public samples.
