Import CRM data into Google Sheets

On this pageSelect the record family and scopePreview fields and rowsSave settings and deliverManage an existing import

By Karthik Anand · Updated October 16, 2026

The planned import journey is Choose data → Import Preview → Settings → Import. Select a source object, choose standard and available custom fields, inspect the sample rows, then choose the destination and refresh settings. A new import reads from the CRM; it does not automatically send worksheet changes back.

Select the record family and scope

Choose the record type that represents your primary dataset. Contacts and opportunities are different objects. Appointment imports also need a calendar and valid date window before field selection. Use filters to keep the export relevant to the reporting decision.

Source availability depends on enabled access and account permissions. Seeing an object in a sample does not establish live access to it. Read the data catalog for current acceptance boundaries.

Preview fields and rows

Keep the record ID when you need stable matching. Select readable names and the dates, ownership, currency, and relationship fields the report requires. Standard and discovered custom fields share one Fields chooser.

Inspect blank values, unassigned records, and custom field types. Reorder columns before running the import. A field or filter change requires a fresh preview before Save & Run.

Save settings and deliver

Choose a clear import name and an unambiguous worksheet destination. Configure a suitable refresh cadence. Import performs the data job; saving a name or schedule on an existing import is a settings operation and does not itself refresh worksheet data.

After delivery, compare a few rows with their source records. Check the last-run result and data scope. Do not read an empty or failed delivery as proof that the source contains no records.

Manage an existing import

Use Open worksheet, Refresh, Edit, and the lifecycle actions in More. Pause stops scheduled activity while preserving previously delivered worksheet data and already accrued usage. Removal and disconnection have separate operational meanings.

Repeated source transfers add usage. Run a refresh when fresh source data is useful, rather than treating it as a harmless display refresh. Ask about a subscription when your recurring volume makes predictable costs preferable.
