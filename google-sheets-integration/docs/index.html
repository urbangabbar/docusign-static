Getting started with CRM Sync

CRM Sync is the in-app name of the Google Sheets integration for GoHighLevel by LC Bridge. The connected product is in early access. Start with an open sample report, then use the existing waitlist to request access. Joining the waitlist does not install the app or authorize account access.

Import CRM data into Google Sheets

The planned import journey is Choose data → Import Preview → Settings → Import. Select a source object, choose standard and available custom fields, inspect the sample rows, then choose the destination and refresh settings. A new import reads from the CRM; it does not automatically send worksheet changes back.

Fields, custom fields, and filters

Choose only the columns and rows needed for the worksheet’s purpose, while retaining identity and report-required fields. The import preview is the place to check standard fields, available custom fields, ordering, and filter behavior before a data run.

Read guide →

Review worksheet changes before updating CRM records

Eligible updates to existing Contacts and Opportunities require Preview changes, Export Preview, and explicit confirmation. Editing a cell, changing update permission, or reconnecting an account does not automatically send outgoing updates.

Read guide →

Create and customize a report

Choose a template, supply its relevant inputs in one form, inspect the sample, and create the report worksheet. A report can reuse compatible source imports. Its metrics still depend on the source grain, relationships, date basis, and available history.

Read guide →

Refresh schedules and record-transfer usage

Choose a refresh cadence based on when your team needs new source data. Manual and scheduled executions that transfer primary records create usage. Updating a chart from data already in the worksheet is a different operation.

Read guide →

Troubleshoot imports, reports, and reviewed updates

Start with the exact failing step: connection, source access, import preview, delivery, report calculation, or outgoing update. Preserve the last valid data and unfinished draft. Missing permissions, empty source data, stale reviews, and uncertain writes need different recovery paths.
