Troubleshoot imports, reports, and reviewed updates

On this pageConnection or source access is unavailableA report shows unavailable dataA number differs from another reportAn outgoing update fails or is uncertain

By Karthik Anand · Updated October 16, 2026

Start with the exact failing step: connection, source access, import preview, delivery, report calculation, or outgoing update. Preserve the last valid data and unfinished draft. Missing permissions, empty source data, stale reviews, and uncertain writes need different recovery paths.

Connection or source access is unavailable

Reconnect the account from the relevant task. Confirm access to both the CRM data and the target spreadsheet. Preserve selected fields, reporting dates, and destination while recovering. A reconnection is not permission to run pending outgoing updates automatically.

An empty field catalog can mean no available fields, missing access, or a load failure. Keep the distinction visible. The same applies to a zero-row import: first check scope, filters, dates, calendar selection, and the job result.

A report shows unavailable data

Read the required sources and coverage. Stage conversion needs observed stage entries and exits. Forecast movement needs a saved cutoff with compatible records. Response metrics need sufficiently complete actor and message sequencing. Current records cannot stand in for those histories.

A missing period should remain unavailable rather than appearing as a zero trend. A partial comparison should not pretend to cover a full prior period. If the report uses a current balance snapshot, changing a period filter does not recreate past balances.

A number differs from another report

Check the grain, date basis, status exclusions, currency, and source relationships. Won opportunity value is not collected cash. An order line is not a second copy of its header total. One contact can contribute several opportunities.

Use the public sample’s chart-data disclosure and metric definitions to see what contributes to a result. In a live workbook, verify the actual source rows before changing formulas simply to make two different measures agree.

An outgoing update fails or is uncertain

Invalid mappings and field types need correction. A stale review needs a new preview. A current-value conflict needs inspection of the source value. A partial result should identify which records succeeded and which did not.

Do not blindly resend an uncertain operation. Reconcile the original receipt so a retry does not duplicate its effects or charges. Contact support with the operation reference and a redacted description; never send access tokens or unrelated customer data.
